# Exclusive Access Page

Create a premium dark landing page with the exact same architecture and animations as a high-end exclusive community site.



Style rules:

- Pure dark background (#050505)

- Completely flat design — no cards, no boxes, no shadows, no borders around sections

- Only subtle hexagon pattern in the hero (very low opacity)

- Clean large typography, generous spacing

- Smooth scroll

- Sections fade + slide up on scroll

- Category pills: click to switch, description cross-fades

- FAQ accordion with smooth height animation

- Buttons have subtle hover scale



Structure (exact order):



1. Sticky navbar

- Left: logo text

- Links: Categories, About, FAQ

- Right: outline button



2. Hero (full viewport)

- Centered content

- Small badge “Limited Spots Available”

- Large bold headline

- Short subtitle

- Two buttons (primary + outline)

- Use the lifestyle photo of the man in white traditional outfit + native cap as background or side image



3. How It Works

- Small label

- Title

- 3 simple steps that appear one after another on scroll



4. Categories section

- Title + short description

- 5 selectable pills: Clothing · Shoes · Watches · Native Caps · Shadda

- When a category is selected, show related product images + short description underneath

  - Clothing → native shirts + fabric rolls

  - Shoes → the two slide images

  - Watches → the three watch images

  - Native Caps → white and blue caps on gold heads

  - Shadda → gold patterned fabric



5. Features / What We Offer

- Title

- 5–6 clean feature items with icons (no cards), staggered fade-in



6. Testimonials

- Title

- Clean quote list that fades in one by one



7. About Us

- Title + two short paragraphs



8. FAQ

- Accordion style with smooth expand/collapse



9. Final CTA

- Centered title + button + small social proof



10. Footer

- Logo, copyright, quick links, socials



Make everything feel exclusive, clean and premium. No cards anywhere.
